# ✅ To-Do List Web App

A dynamic and responsive To-Do List web app built with Flask, SQLAlchemy, SCSS, SQLite, and pure frontend logic — stylish, structured, and storage-backed.


## 💡 Features

* 📅 **Date-Time Picker** using `datetime-local` for scheduling tasks
* 📋 **Task List Table** with real-time rendering
* ✅ **Manual Checkboxes** to track task completion
* 🖌️ **Custom Styling** with SCSS variables for easy theming
* 💾 **Persistent Storage** using SQLite and SQLAlchemy ORM
* 📱 **Mobile-Friendly UI** with responsive design via media queries
* ⚡ **Frontend-Driven Interaction** — no backend business logic required

---

## 🛠️ Technologies Used

* **Flask** – lightweight Python web framework
* **SQLAlchemy** – ORM for handling the SQLite database
* **SQLite** – database for storing task records
* **SCSS (SASS)** – modular and variable-based styling
* **HTML5 + CSS3** – structured layout and style
* **Jinja2** – templating for dynamic rendering

## 🚀 How to Run Locally

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
pip install flask sqlalchemy
python app.py
```

> Access it at `http://127.0.0.1:5000/`
